# DS 编写 Skill

- DS 是 RTL 实现前的候选详细设计，不是对 AS 的摘要。
- 对 AS 中每个子模块描述职责、输入条件、输出行为、内部状态、组合/时序逻辑、异常处理和关键电路文字方案。
- 描述子模块内部接口的方向、位宽、语义、握手、时序和背压；外部接口引用架构基线，不擅自重定义。
- 必须覆盖 Clock、Reset、初始化、边界条件、错误恢复、性能约束和开放问题。
- 用户补充正式关键电路图；Agent 只给出电路图应表达的内容和编号。
- 所有没有文档证据的细节标记为假设或 TODO，不得写成既定事实。
- 输出为 Markdown Candidate，必须经过独立评审和用户确认。
